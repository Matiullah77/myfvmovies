A full page combining both layout systems:

## Summary of Work Process
I started with the simpler Flexbox tasks (navigation bar and card row) before moving on to CSS Grid, since Flexbox felt more intuitive for arranging items in a single row or column, while Grid was better suited for structuring a full page layout with defined areas like header, sidebar, main content, and footer. The main challenge I faced was combining both systems in the portfolio page (Task 4) — deciding where Flexbox should handle alignment inside smaller components (like the navbar and project cards) versus where Grid should control the overall page structure. Working through this helped me understand that Flexbox works best for one-dimensional layouts, while Grid is better for two-dimensional, page-level layouts.
